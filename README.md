# AIArtExtendedPlus

## Setup
- Clone Repo
- Install ComfyUI, refer to _https://github.com/comfyanonymous/ComfyUI?tab=readme-ov-file#installing_
- Set correct paths in TextToImage and ImageToImage C# and Python Scripts
- Verify Prompt and Result Locations in ComfyUI Workflows


## Run CV Version on Samsung Frame
- Launch ComfyUI via _run_nvidia-gpu.bat_
- Start Logitech Webcam Software
- Run Python CV Tracking Script _Tracking.py_ located at AIArtExtendedPlus\PythonCode
- Launch a built version of the Application (Folder on Desktop of AIArt PC)
